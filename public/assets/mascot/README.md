# 尘龙吉祥物素材（待放入原创图）

本目录预留给「尘龙 ChenLong」的原创吉祥物与品牌图。**当前阶段所有页面都没有引用任何图片**，
首页 Hero 右侧、登录页品牌位与聊天页头像位使用纯 CSS 绘制的光晕 / 云朵 / 龙角形状 + 「尘龙」文字标识作为占位，
刻意不使用 emoji 或外部图片链接。

## 约定文件名

| 文件名 | 用途 | 建议尺寸 |
| --- | --- | --- |
| `logo.png` | 导航栏、页脚、后台侧栏的 Logo（透明背景） | 512 × 512 |
| `mascot-hero.png` | 首页 Hero 右侧主视觉 | 1024 × 1024 |
| `mascot-chat.png` | 聊天页头像 / 欢迎卡形象 | 512 × 512 |

## 替换方式

1. 把原创图按上表命名放入本目录；
2. 首页把 `.mascot-stage` 内的占位节点替换为 `<img src="assets/mascot/mascot-hero.png" alt="尘龙">`；
3. 导航与页脚把 `.cl-logo__mark` 换成 `logo.png`（保留文字标识作为降级）；
4. 聊天页把 `.chat-welcome__avatar` 的文字占位换成 `mascot-chat.png`。

## 注意

- 图片必须离线可用，禁止引用 CDN 或外部图床。
- 视觉规范：主色 `#65BFFF`、辅助色 `#A99BFF`、强调色 `#35D5FF`，圆润 Q 版科技风，大圆角与柔和阴影。
- 建议同时提供 WebP 版本以减小体积，`<img>` 用 `<picture>` 兜底。
